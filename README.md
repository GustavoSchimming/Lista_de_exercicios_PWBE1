## Exercícios

Esta atividade contém exercícios básicos de PHP para praticar:

* Condições com `if` e `else`
* Operador lógico `&&`
* Estrutura de repetição `for`
* Arrays e `foreach`
* Funções
* Cálculos matemáticos

## Exercícios realizados

### Exercício 1

Cálculo do valor total de uma compra, com aplicação de 10% de desconto para compras acima ou iguais a R$ 200,00.

### Exercício 2

Verificação da aprovação de um aluno utilizando média e quantidade de faltas.

### Exercício 3

Exibição da tabuada de um número utilizando `for`.

### Exercício 4

Cálculo da média, maior nota e menor nota de uma turma utilizando `array` e `foreach`.

### Exercício 5

Criação de uma função para calcular o IMC utilizando peso e altura.
